# RJN PRINT PORTAL v2.1

Local customer + admin service portal prototype.

## Service management
From the Admin Dashboard, use **+ Add Service** or **Edit / Charge**.
You can change:
- service name
- price/charge in rupees
- description
- icon
- customer instructions
- customer form fields (key, label, type, required/optional)
- required documents
- enabled/disabled status

Disabled services can be enabled again from the service list.

## Run
1. Install Node.js LTS.
2. Open Command Prompt in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

Default admin login for this prototype:
- Email: `admin@rjnprintportal.local`
- Password: `ChangeMe123!`

Change the admin credentials/session settings before any real deployment. This prototype is not production-ready and should be secured and legally reviewed before handling real customer identity documents or payments.
